## Product

Trend Atlas is a region-first investigation tool with a dedicated map view. Choose an Earth science variable, select a region and a date window, and see the measured time series, how fast it is changing, and how strong the evidence is. Add a second region to compare the same variable over the same years. A high school student can read the result in one sentence. A researcher can inspect the source, coverage, aggregation, model, confidence interval and export. Both work from the same analysis result.

**Atlas screen.** Keep the homepage masthead at the top, with a horizontal row for Explore, Map and Analyze. Open on a dark Apple Weather–inspired dashboard with the interactive globe next to the selected region’s latest value, rate and recent observations. Expand the map in place to make the NASA Blue Marble globe the focus, and preserve camera and selection when toggling size. Use slightly rounded corners, subtle separators and native system typography. Let users select the primary and optional comparison regions from the map or keyboard-accessible controls, with the same selections and controls in Analyze. Crossfade views and backdrop colors when motion is allowed.

- **Explore** shows the annual value, signed trend rate, a plain-language evidence label and recent observations. Put confidence interval, observation count, coverage and paired difference behind More statistics. Use amber for supported increases, blue for supported decreases and a neutral backdrop for inconclusive or unavailable results. The backdrop encodes the fitted trend across the selected study period. Keep it separate from the selected year's anomaly and from the numeric map overlay legend.
- **Analyze** opens with credited photography from the selected region, a legible scrim, and a plain-language finding with the signed rate and interval. Use lime for primary actions and the main rate on the dark photo. For selections without matching photography, use a neutral backdrop. Put annual observations in view and keep charts and method checks within easy reach. Analyze exposes the exact source field, product version, units, aggregation, sample size, missingness and coverage, date window, two-sided p-value, slope interval and method notes. Include accessible tables, CSV export and a shareable URL for published data. When comparing compatible regions, fit the same model to the paired year-by-year A-minus-B series. Show its signed slope, interval and common annual sample count. Give each region its own evidence statement and use only the paired fit to make a statement about the difference.
- **Timeline** plays annual map frames on explicit request, using a fixed display scale for the variable across frames. Tapping or focusing the chart highlights the corresponding frame where available. Keep the analysis window independent of the selected frame. Provide `Observed values` and, if verified, a `Trend` layer with a signed per-decade legend. Regional significance belongs to the selected region, so keep it out of individual map cells unless a separately validated spatial testing method is implemented.
- **Projection** uses one MapLibre GL JS instance with built-in globe and Mercator projections. Keep selected regions, data layers, date, legend, comparison results and camera target in shared state. Verify camera framing, pins and layer alignment in both projections, including around the antimeridian. Use a short transition where supported, an immediate switch for reduced motion, and an explanatory local fallback with a static map and fully usable chart and region controls if WebGL is unavailable. Globe and flat map must work with the same data layer before visual polish.
- **3D Surface** is a chart view of the selected area's time series. X is year, Y is month and Z is the value in its original units. Use the map layer's fixed anomaly scale and a visible zero plane. Clicking a cell or changing the month/year controls reveals its exact month, value, unit and coverage. Add `2D heatmap` as a readable companion for small screens and an accessible table. These surfaces use real regionally aggregated monthly rows. Disable the surface with an explanation for datasets with annual-only input. Mark gaps in the mesh where rows are missing. For the polar demo, select a region with a labeled gridded monthly series as the surface input while the annual comparison stays explicitly linked to the published table.

### Analysis contract

- Store stable metadata for each dataset and import, including product and field, version, units, grid resolution, retrieval date, source URL/DOI, input checksum, date range, transformations, missing-value policy and artifact checksums. Decode CF units, calendars, scale/offset and fill values correctly. Test latitude/longitude order and normalize longitude at ingest. Restrict the first release to named regions and coordinate boxes, with validated bounds and explicit antimeridian handling.
- Compute regional monthly means with geographic cell-area weights and fractional box overlap, or clearly document and label any fallback approximation. Use a fixed, eligible cell footprint across each analysis window, report its area coverage relative to the region, and suppress inference below a documented coverage threshold. Leave missing values missing. State any upstream weighting for Giovanni exports and report unknown coverage as unknown. Never imply a preset export has the same weighting as a custom grid query without checking.
- Aggregate temperature anomalies by a calendar-day-weighted average of complete years and precipitation as complete-year totals. Display monthly records with visible breaks plus annual results. Apply the requested date window to the analysis, and report the actual used years, sample count, exclusions and gaps. Label annual precipitation and its trend clearly, for example `annual total (mm)` and `change in annual total (mm per decade)`.
- Fit OLS to annual values against centered actual calendar years. Multiply slope and interval endpoints by ten. Use statsmodels HAC covariance with Bartlett weights, `maxlags=2`, small-sample correction and `use_t=True` on contiguous annual input. Report the two-sided slope p-value and 95% interval from that same fit at α = 0.05. Treat 20 contiguous complete annual observations as a product threshold for inference. Show the series and a labelled descriptive slope for shorter or gapped records where estimable, with an explicit reason that inference is unavailable. Treat degenerate variance and unavailable coverage diagnostics as explicit states. Describe the interval as model-based and show the observational coverage separately. Keep any chart band explicitly identified as the fitted mean interval, with the slope interval separately in the result. [Statsmodels robust covariance documentation](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.RegressionResults.get_robustcov_results.html)
- Compute the paired case on the intersection of eligible years using the same variable, compatible aggregation and units. For a published headline comparison require support under annual HAC lags 1, 2 and 3, keep lag 2 as the declared primary result, and show an explicit `Sensitive to method` note if whether the 95% interval excludes zero changes. HAC is an approximation with finite annual samples, so keep the model and date window in the scoped claim. Record a residual-correlation diagnostic and the sensitivity results in the evidence export. When using arbitrary periods, label user-chosen analyses exploratory. Reserve spatial significance maps and mass testing for a later build with a defined multiple-testing policy.
- Run the demo pair on identical dates with real source files. Choose two regions from a documented scientific or educational question before looking at p-values, for example northern versus southeastern Australia precipitation, and report whatever the app finds. Earn the opposite-direction moment through verified data and scope, with a transparent exploration label if the examples were selected after looking. A strong trend versus an inconclusive result also makes a good demo. Cover short, flat, rising, falling, gapped, seasonal, sparse and correlated cases in verification. Test known signed slopes and unit conversions, compare one real slice against an independent calculation and check exact agreement between Explore, Analyze and exports.
